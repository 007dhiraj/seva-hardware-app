SEVA Hardware Android App

Direct-install Android debug APK build. Google Play Store पर publish नहीं किया जाता।

  1. Repository में GitHub Actions खोलें।
  2. Build SEVA Hardware installable APK चलाएँ।
  3. Green/success run के Artifacts से SEVA-Hardware-Android-APK डाउनलोड करें।
  4. ZIP extract करके app-debug.apk फोन में install करें।

मौजूदा build offline/local है। Cloud database, multi-branch login और automatic sync अभी उपलब्ध नहीं हैं। App data इसी phone में रहता है; नियमित JSON backup रखें।
