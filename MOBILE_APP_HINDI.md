# Seva Hardware Mobile App\n\n- Open the GitHub Pages site for this repository in Chrome on Android.\n- Use Chrome menu > Add to Home screen / Install app.\n- Sales, stock and customer entries are saved locally in this browser using localStorage.\n- This is an offline-first mobile web app; it does not yet provide cloud sync, multi-branch accounts, server backup or a signed Android APK.\n- Do not clear browser data unless you have separately recorded your business records.\n
