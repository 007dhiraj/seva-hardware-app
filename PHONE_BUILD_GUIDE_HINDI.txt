FREE BILL — ANDROID APK

यह project GitHub Actions से सीधे install होने वाली Android debug APK बनाता है। Play Store/AAB नहीं बनता।

APK लेने के steps:
1. Repository खोलें: https://github.com/007dhiraj/seva-hardware-app
2. Actions tab खोलें।
3. “Build Free Bill installable APK” workflow चुनें।
4. Run को green/success होने दें। Android emulator में install और launch check पूरा होना जरूरी है।
5. Successful run खोलें और Artifacts में “Free-Bill-Android-APK” ZIP डाउनलोड करें।
6. ZIP extract करें और app-debug.apk पर tap करें। Android पूछे तो Files/Chrome के लिए Install unknown apps अनुमति दें।
7. Free Bill खोलकर अपना mobile number और local PIN बनाएं।

Backup:
More → Settings & Backup → Download full backup चुनें। Android share sheet से JSON file को Files/Drive में सुरक्षित रखें। Restore backup में वही JSON file चुनें; restore मौजूदा account data replace करता है।

सीमाएँ:
Data इसी फोन में रहता है। Cloud database, multi-branch login, automatic sync, OTP और Forgot-PIN recovery अभी लागू नहीं हैं। PIN salted PBKDF2-SHA256 hash (120,000 iterations) में रहता है; पुराने accounts सफल login पर upgrade होते हैं। Business data encrypted नहीं है। App uninstall या app data clear करने से data मिट सकता है। नियमित backup रखें। GST calculation basic है; HSN, GST rate, place of supply, discount और कानूनी invoice rules CA/GST professional से verify करें।
