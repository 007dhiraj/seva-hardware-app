# Free Bill — Development Roadmap

## Active focus
Stabilize the existing Android demo and address outdated-build confusion before adding more features.

## Milestones
1. **Reproducible build** — verify repository source, workflow, artifact naming, version/build stamp.
2. **QA fixes** — run business-logic tests and emulator smoke tests; fix regressions.
3. **Core billing polish** — GST/non-GST mode, discounts, additional charges, invoice/ledger sharing, item/customer search and usability.
4. **Security & data** — replace insecure local PIN storage; plan OTP; document cloud sync/tenant isolation before implementing.
5. **Release testing** — test APK on a real Android phone, backup/restore and PDF/share paths.

## Truthful current baseline
The current README describes a local-only app. OTP, secure PIN storage, cloud sync, multi-branch access and full statutory GST compliance are not implemented yet. Each milestone must be verified before it is marked complete.
